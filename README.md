# Network search engine

<p>This is a desktop application developed in Java that allows users to store and search for information across a network.</p>

---

## Features
- The app stores information in a .csv file, which can be easily accessed and updated.
- Users can detect public IP addresses, and get information about the network.
- The user has to change the IP adress from the source code in order to get the information from it.

---

## Technologies Used
- Java: The primary programming language used for developing the application.
- CSV: The format used for storing information in a structured manner.
- Java Swing: Used for creating the graphical user interface (GUI) of the application.
- Network libraries: Utilized for retrieving network information and detecting public IP addresses.

---

## Usage
1. Clone the repository to your local machine.
2. Open the project in your Java IDE (e.g., Eclipse, IntelliJ IDEA).
3. Update the IP address in the source code to the desired target.
4. Run the application to start searching for information across the network.
5. The application will display the results in the console, in the .csv file, and in the GUI.

---

### Note
- Ensure that you have the necessary permissions to access the network and retrieve information.
- The application is intended for educational purposes and should be used responsibly.
- Always respect privacy and legal guidelines when accessing network information.
